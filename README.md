# homebrew-tap

**简体中文** | [English](#english)

[tapefox](https://github.com/Egdon/tapefox) 的 Homebrew 软件源。tapefox 是磁带卡座风格的命令行网易云音乐客户端。

```sh
brew install egdon/tap/tapefox
```

`Formula/` 中的文件由 tapefox 的发布流程自动生成，请勿手动修改。

## English

Homebrew tap for [tapefox](https://github.com/Egdon/tapefox), a terminal client for NetEase Cloud Music with a cassette-deck interface.

```sh
brew install egdon/tap/tapefox
```

The files in `Formula/` are generated by the tapefox release workflow and should not be edited by hand.
