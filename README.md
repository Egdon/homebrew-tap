# homebrew-tap

**简体中文** | [English](#english)

[musicfox-deck](https://github.com/Egdon/musicfox-deck) 的 Homebrew 软件源。musicfox-deck 是磁带卡座风格的命令行网易云音乐客户端。

```sh
brew install egdon/tap/musicfox-deck
```

`Formula/` 中的文件由 musicfox-deck 的发布流程自动生成，请勿手动修改。

## English

Homebrew tap for [musicfox-deck](https://github.com/Egdon/musicfox-deck), a terminal client for NetEase Cloud Music with a cassette-deck interface.

```sh
brew install egdon/tap/musicfox-deck
```

The files in `Formula/` are generated by the musicfox-deck release workflow and should not be edited by hand.
